# 研间 · 个人科研工作台

一个在个人电脑上运行的科研与教学工作台。首页集中呈现今日事项、完成记录、关键项目进度和近期提醒；项目、学生和事务资料保留在本地。

## 本次更新

- **首页 AI 小助手**：接入硅基流动，通过对话整理任务、科研项目、阶段、组会和学生指导记录；核对草案后一键添加，支持继续修改和安全撤销。仅在明确要求时拆解任务。
- **任务删除**：日常任务行和编辑窗口都可删除任务，确认后同步更新首页及关联列表，保留关联档案。
- 移除“导入工作方案”入口，已有导入记录继续保留。

- **任务提醒**：近期、以后任务可选择提醒日期，到期显示在首页；完成、关闭提醒或安排为今天做后移出提醒区。
- **一键跟进**：首页选择学生、填写实际日期及内容，保存为指导记录，并计入实际日期的完成统计。
- **任务相关人员**：支持负责人、发起方或部门；已有合作者可关联，组会关联收进可选区域。
- **合作者管理**：协助评阅求助人自动建立潜在档案；项目中可直接填写新合作者。合作者与潜在合作者分区显示，各自按职称或项目优先情况排序。
- **首页操作**：关键项目可点击图钉直接取消置顶。

保持本地运行。AI 为可选功能，使用前在首页助手的“AI 设置”中填写自己的硅基流动密钥并选择模型；不用 AI 也可照常管理记录。已有记录继续使用原有数据目录；更新程序前建议通过设置导出备份，不要覆盖自己的 data 目录。

## 功能

- **日常任务**：今天、近期、以后和已完成，支持临时插入标记、截止日期和关联记录。
- **科研项目**：学术论文、项目申报、其他事项；按阶段权重计算进度，甘特图支持起止日期和“至今”。
- **论文去处**：目标期刊、多次投稿、返修及录用记录。
- **学生管理**：培养类型、研究方向、毕业节点、指导记录、反馈、任务和跟进日期。
- **组会与合作者**：组会议题和记录、后续安排、独立合作者档案及关联项目。
- **事务管理**：行政任务、期刊审稿、学生工作、协助评阅，四类分别关联文件夹。
- **完成汇总**：任务、指导记录和已完成组会统一汇总到首页；已完成事项不再显示逾期。
- **本地文件**：浏览关联目录及子目录，交给本机默认软件打开文档。
- **数据与备份**：本地 JSON，保存时备份，最多保留100份；支持导入和导出。
- **界面**：紧凑首页、文档式详情，浮世绘、莫奈、梵高画作；项目和学生可拖动排序。

### 学习后如何开始正式使用

在“设置与备份 → 学习示例”选择 **清除示例，开始正式使用**：

- 清除所有带示例标记的记录，包括你对示例记录的编辑。
- 保留自己新建的记录；如果它们关联到被清除的示例，会解除对应关联。
- 操作前自动备份。虚拟资料文件保留在 `data/demo-files`，不删除任何实际文件。
- 清除后重新启动不会再次自动载入。只有空白工作台才能手动载入示例。
- 已有真实资料的工作台升级时保持原样。

## 从源码运行

需要 Node.js 22.13 或更新版本、npm、Python 3.10 或更新版本（当前验证使用3.13）。

```sh
npm ci
npm run build
```

### Mac

```sh
python3 launch.py
```

或双击“启动研间.command”。首次需要先完成上述构建。浏览器打开 http://127.0.0.1:4318/ ，启动后可关闭终端。

### Windows 10/11

在项目根目录完成相同的 npm 构建，然后：

```powershell
py -3 windows/launch_windows.py
```

保留启动窗口，可最小化；关闭窗口即退出。Windows入口适配文件夹选择和默认软件打开。源码依赖系统Python，免安装分享包则内置运行时。

**重启电脑或退出研间后，需要重新启动程序。浏览器收藏只保存网址，不会启动本地服务。**

## 数据边界

源码不包含真实个人记录、学生档案、备份、API密钥或实际关联文件夹路径。新工作台首次启动载入下述虚拟示例，已有工作台不会自动插入。

- Mac源码版：`data/workspace.json`，备份在`data/backups/`。
- Windows：`%LOCALAPPDATA%/ResearchDesk/data`，独立于程序目录。
- JSON备份含你后来设置的目录路径，不含原始Word、Excel等文件，文档需另行备份。
- 服务只监听本机回环地址。GitHub仓库用于保存程序代码，并不会同步你的工作台数据。
- 支持本地保存版本冲突检查和关联目录边界检查。

## 开发与测试

前端 React / TypeScript / Vinext，后端 Python 标准库。

```sh
npx tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

开发调试时，在两个终端分别运行：

```sh
python3 server.py --port 4319
npm run dev
```

测试使用临时数据目录，HTTP测试会临时监听本机端口。

## AI 小助手

详见[对话助手说明](对话助手说明.md)。例如：“今天临时帮王老师评阅项目申报书，周五前反馈”。助手先生成草案，确认后写入，可继续对话修改。

调用会将本次对话发送到硅基流动；已有档案名称仅在勾选后发送，不读取本地文件夹。密钥保存在数据目录同级的 `private-ai/siliconflow.json`，不进入普通备份或 Git 仓库。该文件未额外加密；请使用个人系统账户妥善保管。API 调用可能产生服务商费用，取消等待不保证取消计费。
