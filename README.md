# 研间 · 个人科研工作台

一个在个人电脑上运行的科研与教学工作台。首页集中呈现今日事项、完成记录、关键项目进度和近期提醒；项目、学生和事务资料保留在本地。

## 功能

- **日常任务**：今天、近期、以后和已完成，支持临时插入标记、截止日期和关联记录。
- **科研项目**：学术论文、项目申报、其他事项；按阶段权重计算进度，甘特图支持起止日期和“至今”。
- **论文去处**：目标期刊、多次投稿、返修及录用记录。
- **学生管理**：培养类型、研究方向、毕业节点、指导记录、反馈、任务和跟进日期。
- **组会与合作者**：组会议题和记录、后续安排、独立合作者档案及关联项目。
- **事务管理**：行政任务、期刊审稿、学生工作、协助评阅，四类分别关联文件夹。
- **完成汇总**：任务、指导记录和已完成组会统一汇总到首页；已完成事项不再显示逾期。
- **本地文件**：浏览关联目录及子目录，交给本机默认软件打开文档。
- **数据与备份**：本地 JSON，保存时备份，最多保留100份；支持导入和导出。
- **界面**：紧凑首页、文档式详情，浮世绘、莫奈、梵高画作；项目和学生可拖动排序。

AI任务分解目前处于讨论阶段，**尚未实现**。

## 从源码运行

需要 Node.js 22.13 或更新版本、npm、Python 3.10 或更新版本（当前验证使用3.13）。

```sh
npm ci
npm run build
```

### Mac

```sh
python3 launch.py
```

或双击“启动研间.command”。首次需要先完成上述构建。浏览器打开 http://127.0.0.1:4318/ ，启动后可关闭终端。

### Windows 10/11

在项目根目录完成相同的 npm 构建，然后：

```powershell
py -3 windows/launch_windows.py
```

保留启动窗口，可最小化；关闭窗口即退出。Windows入口适配文件夹选择和默认软件打开。源码依赖系统Python，免安装分享包则内置运行时。

**重启电脑或退出研间后，需要重新启动程序。浏览器收藏只保存网址，不会启动本地服务。**

## 数据边界

源码不包含个人记录、学生档案、备份、API密钥或实际关联文件夹路径。首次启动为空白。

- Mac源码版：`data/workspace.json`，备份在`data/backups/`。
- Windows：`%LOCALAPPDATA%/ResearchDesk/data`，独立于程序目录。
- JSON备份含你后来设置的目录路径，不含原始Word、Excel等文件，文档需另行备份。
- 服务只监听本机回环地址。GitHub仓库用于保存程序代码，并不会同步你的工作台数据。
- 支持本地保存版本冲突检查和关联目录边界检查。

## 开发与测试

前端 React / TypeScript / Vinext，后端 Python 标准库。

```sh
npx tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

开发调试时，在两个终端分别运行：

```sh
python3 server.py --port 4319
npm run dev
```

测试使用临时数据目录，HTTP测试会临时监听本机端口。
